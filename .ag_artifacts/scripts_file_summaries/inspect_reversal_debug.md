# inspect_reversal_debug.py

## Overview

**Path:** `./scripts/inspect_reversal_debug.py`

**Purpose:**  
scripts/inspect_reversal_debug.py

Small utility to inspect reversal debug CSVs and (optionally) merge with accepted reversal timestamps.

Usage examples (from project root):

# Show top 20 debug rows (sorted by ms_aggr desc):
python -u scripts/inspect_reversal_debug.py

# Show top 20 debug rows from a specific debug CSV:
python -u scripts/inspect_reversal_debug.py --debug out/labels_v02/reversal_debug.csv

# Merge accepted reversals from labels-only file (labels_only_v02_*.csv) and show merged top 20:
python -u scripts/inspect_reversal_debug.py --labels out/labels_v02/labels_only_v02_20251128_151519.csv

# Merge and print merged rows:
python -u scripts/inspect_reversal_debug.py --debug out/labels_v02/reversal_debug.csv --labels out/labels_v02/labels_only_v02_20251128_151519.csv
