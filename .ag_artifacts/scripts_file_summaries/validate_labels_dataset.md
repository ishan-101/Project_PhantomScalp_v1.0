# validate_labels_dataset.py

## Overview

**Path:** `./scripts/validate_labels_dataset.py`

**Purpose:**  
scripts/validate_labels_dataset.py

Validator for label datasets (train/val/test) with AUTO-DETECTION.

Features:
- If explicit CSV paths are provided with --csvs, those are used.
- Otherwise the script searches the provided --data-dir (and common subfolders)
  for files matching patterns like '*_train.csv', '*train.csv', etc.
- If multiple candidate triplets exist, the script picks the triplet with the
  newest timestamp (by timestamp in filename if present, else by mtime).
- Output report ALWAYS saved to root-level 'out/' folder (default: out/validate_report.md)

Usage examples:
  # 1) Let the script auto-discover datasets under out/datasets_v02
  python scripts/validate_labels_dataset.py --data-dir out/datasets_v02

  # 2) Auto-discover under the repo and use default out/
  python scripts/validate_labels_dataset.py

  # 3) Provide explicit filenames (relative to data-dir)
  python scripts/validate_labels_dataset.py --data-dir out/datasets_v02       --csvs labels_dataset_v02_20251128_175517_train.csv              labels_dataset_v02_20251128_175517_val.csv              labels_dataset_v02_20251128_175517_test.csv

  # 4) Provide absolute paths
  python scripts/validate_labels_dataset.py --csvs /abs/path/train.csv /abs/path/val.csv /abs/path/test.csv

Outputs:
  - Markdown report saved to root 'out/' directory (default filename validate_report.md)
  - Exit code 0 if no major issues, 2 if suspicious issues found
