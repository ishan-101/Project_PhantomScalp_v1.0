# prepare_labels_dataset.py

## Overview

**Path:** `./scripts/prepare_labels_dataset.py`

**Purpose:**  
scripts/prepare_labels_dataset.py

Prepare labeled dataset for Project_PhantomScalp v0.2:
 - loads an optional spot CSV of OHLCV (expects datetime column or index)
 - otherwise generates a full synthetic OHLCV timeseries (open/high/low/close/volume)
 - computes features via app.features.time_cycle, microstructure, options_features (defensive)
 - runs labelers (regime, reversal, cycle) from app.ml.labels (defensive)
 - writes train/val/test splits (parquet + csv) and labels-only CSV and meta JSON

Key points:
 - defensive: never raises on missing feature columns; labelers receive sensible fallbacks
 - timezone-safe: produce tz-aware UTC index by default
 - avoids deprecated pandas patterns (uses .ffill()/.bfill(), pct_change(fill_method=None))
 - creates timestamped outputs in the target directory
