# scan_fix_pandas_deprecations.py

## Overview

**Path:** `./scripts/scan_fix_pandas_deprecations.py`

**Purpose:**  
Scan & optionally fix pandas deprecation patterns:
 - fillna(method='ffill'/'bfill')  -> .ffill()/ .bfill()
 - pct_change(... ) without fill_method -> add fill_method=None

Usage:
  # dry-run (report only)
  python scripts/scan_fix_pandas_deprecations.py --report

  # actually apply fixes (will create .bak backups)
  python scripts/scan_fix_pandas_deprecations.py --apply

Notes:
 - Script is conservative: only applies simple textual transforms and creates backups.
 - Review diffs (bak -> original) if you want to revert.
